# AI Text Detector

Project for the AI Applications for Digital Business module at GISMA. The idea is to check if an essay was written by a person or generated by an LLM like ChatGPT.

## What it does

Takes an essay as input and gives the probability that it is AI generated. I trained two models and compared them:

1. TF-IDF (character n-grams) + Logistic Regression - the simple one
2. DistilBERT fine tuned - the deep learning one

The main thing I was careful about is the train/test split. I split by essay prompt instead of randomly, so the test set only has topics the model has never seen. Otherwise the model could just memorise the topic words and get a high score without actually learning anything about how AI writes.

## Dataset

DAIGT v2 from Kaggle: https://www.kaggle.com/datasets/thedrcat/daigt-v2-train-dataset

65,508 essays, 15 different prompts. 27,371 are real student essays (from the PERSUADE corpus) and 38,137 are generated by around 20 different LLMs (GPT-4, Llama 70B, Mistral 7B, Claude, Falcon 180B, PaLM etc).

The csv is around 150MB so its not in the repo. Download it from Kaggle and put it in `data/daigt_v3.csv`.

## Results

Tested on 8,544 essays from 3 prompts that were not in training.

| Model | Accuracy | F1 | ROC-AUC |
|---|---|---|---|
| TF-IDF + Logistic Regression | 0.962 | 0.963 | 0.994 |
| DistilBERT | 0.974 | 0.975 | 0.997 |

Some things I found:
- The TF-IDF model is almost as good as DistilBERT and trains in like a minute on CPU. DistilBERT takes ~10 min on a GPU for 1 extra point of accuracy.
- Mistral 7B instruct and Llama 70B essays were the hardest to catch (~93-95%). GPT-4, Falcon 180B, PaLM etc got caught almost every time.
- Most of the mistakes are human essays that are very formal and well structured, so they look like AI wrote them.

## How to run

```
pip install pandas numpy matplotlib scikit-learn torch transformers jupyter
jupyter notebook AI_Text_Detector.ipynb
```

The notebook already has all the outputs saved so you can just read through it without running anything. If you want to run the DistilBERT part you need a GPU (or use Colab with GPU runtime and change the csv path to `/content/daigt_v3.csv`).

## Limitations

- All the human essays are from one dataset of US student writing so the model might be learning that style specifically and not "human writing" in general
- The AI essays are from 2023-24 models, newer ones might be harder to detect
- Didnt test paraphrased or edited AI text
